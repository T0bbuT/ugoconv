iPhone ショートカット（実験版 v0.2.2）

Userscripts アプリなしで、Safari の共有メニューから変換して保存します。

1. コードをコピー

2. ショートカットを作る（アクション 1 つだけ）

  1. 「ショートカット」アプリで右上の ＋。名前を うごイラ変換 にする
  2. 下の ⓘ（詳細） で 共有シートに表示 をオン。一番上の「共有シートから○○を受け取る」の種類は Safari Web ページ だけにする
  3. アクション Web ページで JavaScript を実行 を追加。中の見本コードを全部消して、1 でコピーしたコードを貼り付ける

「Web ページで JavaScript を実行」が動かない場合は、設定 → アプリ → ショートカット → 詳細 → スクリプトの実行を許可 をオンにしてください。

（任意）pixiv アプリから使うためのショートカット

pixiv アプリの中ではコードを動かせないので、まず Safari で作品を開くためのショートカットを別に作ります。

  1. 新しいショートカットを作り、名前を Safariで開く にする。共有シートに表示 をオンにし、受け取る種類を URL と テキスト にする
  2. アクション テキストを照合 を追加。パターンに (?<=artworks/)\d+、対象に「ショートカットの入力」
  3. アクション テキスト を追加し、x-safari-https://www.pixiv.net/artworks/ と入力して、続けてキーボード上の候補から「一致」を差し込み、最後に #ugoconv=mp4 と入力する（余計なスペースが入らないように注意。Userscripts を入れている人は、Safari で開いた時点で自動変換が始まります）
  4. アクション URL を開く を追加し、開く対象を「テキスト」にする

使い方: pixiv アプリの共有 → Safariで開く → Safari で開いたら、Safari の共有 → うごイラ変換。

3. 試す

  1. Safari で pixiv にログインし、うごイラの作品ページを開く
  2. Safari 自体の共有メニュー（アドレスバー左のアイコン →「共有」）→ うごイラ変換。pixiv のページ内にある共有ボタンではありません。初回は pixiv での実行を「許可」
  3. ショートカットはすぐ終わり、ページ右下のパネルで変換が進む
  4. 終わったら 保存する →「ビデオを保存」で写真に入る
