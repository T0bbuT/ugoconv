iPhone ショートカット（v0.3.0）

Userscripts アプリなしで、Safari の共有メニューから変換して保存します。

できあがったものを使う

ショートカットを追加

このショートカットは、実行のたびに GitHub で公開しているコード の最新版を GitHub Pages から読み込んで動きます。利用者のデータをどこかに送ることはありません。

以下は自分で作る場合の手順です。

1. コードをコピー

数行の「読み込み係」です。実行のたびに GitHub Pages から最新の変換コードを読み込むので、更新があってもショートカットを入れ直す必要はありません。

2. ショートカットを作る

1 つのショートカットで、pixiv アプリから呼んだ時は「Safari で開く」、Safari から呼んだ時は「変換する」を切り替えます。

  1. 「ショートカット」アプリで右上の ＋。名前を うごイラ変換 にする
  2. 下の ⓘ（詳細） で 共有シートに表示 をオン。一番上の「共有シートから○○を受け取る」の種類を Safari Web ページ・URL・テキスト の 3 つにする
  3. アクション 種類を取得 を追加（入力は「ショートカットの入力」）
  4. アクション テキストを照合 を追加。パターンに Safari、対象（青い文字）をタップして「種類」にする
  5. アクション if を追加し、青い文字をタップして「一致」にする（「一致 任意の値 の場合」となれば OK）
  6. 「if」と「その他」の間に Web ページで JavaScript を実行 を入れる。入力（青い文字）をタップして「ショートカットの入力」にし、中の見本コードを全部消して、1 でコピーしたコードを貼り付ける
  7. 「その他」と「if の終了」の間に、次の 3 つを入れる
    1. テキストを照合: パターンに (?<=artworks/)\d+、対象に「ショートカットの入力」
    2. テキスト: x-safari-https://www.pixiv.net/artworks/ と入力し、続けてキーボード上の候補から「一致」（すぐ上の artworks の照合の結果）を差し込み、最後に #ugoconv=mp4（余計なスペースが入らないように注意）
    3. URL を開く: 開く対象を「テキスト」にする

出来上がりはこの形です。追加したアクションは一番下に入るので、長押しでドラッグして位置を合わせてください。

種類を取得（ショートカットの入力）
テキストを照合 Safari（対象: 種類）
if 一致 任意の値 の場合
    ショートカットの入力 に対して JavaScript を実行（コードを貼る）
その他の場合
    テキストを照合 (?<=artworks/)\d+（対象: ショートカットの入力）
    テキスト x-safari-https://www.pixiv.net/artworks/［一致］#ugoconv=mp4
    テキスト を開く
If文の終了

よくある間違い: アプリ用の 3 つが「その他の場合」より上に入っていると、Safari から呼んだ時にページが開き直されて変換が消え、アプリから呼んだ時は何も起きません。

「Web ページで JavaScript を実行」が動かない場合は、設定 → アプリ → ショートカット → 詳細 → スクリプトの実行を許可 をオンにしてください。

3. 試す

  1. Safari で pixiv にログインしておく（R-18 を変換するのに必要。アプリのログインとは別です）
  2. pixiv アプリから: 作品の共有 → うごイラ変換 → Safari で作品が開く → 次の手順へ
  3. Safari で: Safari 自体の共有メニュー（アドレスバー左のアイコン →「共有」）→ うごイラ変換。pixiv のページ内にある共有ボタンではありません。初回は pixiv での実行を「許可」
  4. ショートカットはすぐ終わり、ページ右下のパネルで変換が進む
  5. 終わったら 保存する →「ビデオを保存」で写真に入る
