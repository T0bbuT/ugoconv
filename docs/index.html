うごイラ変換（試作）

pixiv のうごイラを、あなたの端末の中で MP4 / GIF に変換して保存します。変換にサーバーを使わないので、運営費がかかりません。ブラウザで pixiv にログインしていれば R-18 作品も変換できます。

使い方

pixiv の作品ページの右下に出る「うごイラ変換」ボタンを押して、MP4 か GIF を選びます。スマホは変換が終わったら「保存する」を押してください（iPhone は「ビデオを保存」で写真アプリに、Android は「ダウンロード」フォルダに入ります）。

最初に一度、使うブラウザで pixiv にログインしておいてください（アプリのログインとは別です）。

PC（Chrome / Edge / Firefox）

  1. 拡張機能 Tampermonkey か Violentmonkey を入れる
  2. スクリプトを追加 を押してインストール

iPhone（おすすめ: ショートカット 1 つだけ）

  1. ショートカットを追加 を押して「ショートカットを追加」
  2. Safari で pixiv にログインしておく（R-18 の変換に必要。アプリのログインとは別です）

Safari で見ている時: Safari の共有メニュー（アドレスバー左のアイコン →「共有」）→ ショートカットを選ぶ → 変換が終わったら「保存する」→「ビデオを保存」

pixiv アプリで見ている時: 作品の共有 → ショートカットを選ぶ → Safari で作品が開くので、上と同じ手順

初回は pixiv での実行を「許可」してください。動かない場合は 設定 → アプリ → ショートカット → 詳細 →「スクリプトの実行を許可」をオンに。中身や自分で作る手順は こちら。

ショートカットは実行のたびに、GitHub で公開しているコードの最新版を読み込んで動くので、更新のたびに入れ直す必要はありません。

iPhone（別の方法: Userscripts アプリ）

準備は多めですが、ボタン 1 つで変換でき、GIF も選べます。

  1. App Store で無料の「Userscripts」アプリを入れ、設定 → アプリ → Safari → 機能拡張 で Userscripts をオンにする
  2. Safari で pixiv を開き、アドレスバーの「ぁあ」（または拡張機能のアイコン）→ Userscripts →「常に許可」で、pixiv に対してだけ許可する
  3. Safari でこのページの スクリプト を開き、アドレスバーの「ぁあ」→ Userscripts からインストール

Android（おすすめ: Chrome にブックマークを 1 つ）

準備（最初の 1 回だけ）

  1. Chrome で pixiv にログインしておく（R-18 の変換に必要。アプリのログインとは別です）
  2. Chrome でこのページを開き、 を押す
  3. 右上の「︙」→「☆」でこのページをブックマーク → 画面下に出る「編集」を押す
  4. 名前を うごイラ変換 に、URL 欄を全部消してコピーしたコードを貼り付け → 左上の「←」で保存

PC の Chrome に同じ Google アカウントでログインしているなら、PC で下の「うごイラ変換」ボタンをブックマークバーへドラッグするだけでも、スマホの Chrome に同期されます。

使うとき

  1. Chrome で pixiv の作品ページを開く（pixiv アプリからは 共有 →「リンクをコピー」→ Chrome のアドレスバーに貼り付け）
  2. アドレスバーに うごイラ と入力 → 候補に出る ☆うごイラ変換 をタップ
  3. MP4 か GIF を選び、変換が終わったら「保存する」。端末の「ダウンロード」フォルダに入り、Google フォトの「デバイス内のフォト」からも見られます

ブックマークは実行のたびに最新版のコードを読み込むので、更新のたびに入れ直す必要はありません。

Android（別の方法: Firefox ＋ Violentmonkey）

作品ページに変換ボタンが常に出ます。

  1. Firefox を入れ、アドオンから Violentmonkey を追加する
  2. Firefox でこのページの スクリプトを追加
  3. Firefox で pixiv にログインし、作品ページ右下のボタンから変換
