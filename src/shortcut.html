iPhone ショートカット（実験版 v__VERSION__）

Userscripts アプリなしで、Safari の共有メニューから変換して「写真」に保存します。

1. コードは 2 種類あります

ショートカットの JavaScript は数秒で打ち切られるので、「変換を始めるコード」と「できたか確かめるコード」に分けています。それぞれ、手順の中で使う直前にコピーしてください。

2. ショートカットを作る

  1. 「ショートカット」アプリで右上の ＋。名前を うごイラ変換 にする
  2. 下の ⓘ（詳細） で 共有シートに表示 をオン。一番上の「共有シートから○○を受け取る」の種類は Safari Web ページ だけにする
  3. アクション Web ページで JavaScript を実行 を追加。中の見本コードを全部消して コード A を貼り付ける
  4. アクション 繰り返す を追加し、回数を 120 にする。以下 5〜11 は「繰り返す」と「繰り返しの終了」の間に入れる
  5. 待機 を追加（1 秒）
  6. Web ページで JavaScript を実行 を追加。入力（青い文字）をタップして ショートカットの入力 にし、中身を コード B に置き換える
  7. if を追加。条件を「JavaScript の結果」が「値がある」にする。以下 8〜11 は「if」と「その他」の間に入れる
  8. Base64 エンコード を追加し、「エンコード」をタップして デコード に変える（入力は「JavaScript の結果」）
  9. 名前を設定 を追加し、名前を ugoira.mp4 にする
  10. 写真アルバムに保存 を追加
  11. このショートカットを停止 を追加

出来上がりはこの形です（字下げは「繰り返す」や「if」の中に入っていることを表します）。追加したアクションは一番下に入るので、長押しでドラッグして位置を合わせてください。

「Web ページで JavaScript を実行」が動かない場合は、設定 → アプリ → ショートカット → 詳細 → スクリプトの実行を許可 をオンにしてください。

3. 試す

  1. Safari で pixiv にログインし、うごイラの作品ページを開く
  2. Safari 自体の共有メニュー（アドレスバー左のアイコン →「共有」）→ うごイラ変換。pixiv のページ内にある共有ボタンではありません。初回は pixiv での実行を「許可」
  3. 右下のパネルで変換が進み、終わると「写真」に MP4 が保存される。うまく保存されなかった時は、パネルの「保存する」から手動でも保存できます
