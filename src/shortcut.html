iPhone ショートカット（実験版 v__VERSION__）

Userscripts アプリなしで、Safari の共有メニューから変換して「写真」に保存します。

1. コードをコピー

2. ショートカットを作る

  1. 「ショートカット」アプリで右上の ＋。名前を うごイラ変換 にする
  2. 下の ⓘ（詳細） で 共有シートに表示 をオン
  3. 一番上の「共有シートから○○を受け取る」の種類をタップし、Safari Web ページ だけにする
  4. アクション Web ページで JavaScript を実行 を追加。入力は「ショートカットの入力」のまま。中の見本コードを全部消して、1 でコピーしたコードを貼り付ける
  5. アクション Base64 エンコード を追加し、「エンコード」をタップして デコード に変える
  6. アクション 写真アルバムに保存 を追加

「Web ページで JavaScript を実行」が動かない場合は、設定 → アプリ → ショートカット → 詳細 → スクリプトの実行を許可 をオンにしてください。

3. 試す

  1. Safari で pixiv にログインし、うごイラの作品ページを開く
  2. 共有ボタン → うごイラ変換（初回は pixiv での実行を「許可」）
  3. しばらく待つと「写真」に MP4 が保存される
